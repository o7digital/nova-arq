# Raquel Hedo — Architecture & Interiors

Mockup commercial premium réalisé avec Astro et React.

## Démarrer

```bash
npm install
npm run dev
```

## Construire

```bash
npm run build
```

Les photographies d'architecture sont des images de démonstration. Remplacez les fichiers `public/assets/space-01.jpg` à `space-04.jpg` par les photographies réelles du portfolio en conservant les mêmes noms, ou modifiez les chemins dans `src/components/ProjectGallery.tsx` et `src/pages/index.astro`.
